# UI Автотесты: Practice Automation

Проект автоматизированного тестирования UI для сайта [Practice Automation](https://practice-automation.com/). 
Разработан в рамках полуфинала с использованием Python, Pytest, Selenium и Allure.

## Стек технологий

* Python 3.12+
* Selenium WebDriver 4+
* Pytest (тестовый фреймворк)
* Allure (генерация отчетов)
* Паттерн проектирования: Page Object Model (POM)

## Установка и запуск

1. Клонируйте репозиторий:
   `git clone <ссылка_на_ваш_репозиторий>`
2. Создайте и активируйте виртуальное окружение:
   `python -m venv venv`
   `source venv/bin/activate` (Linux/macOS) или `venv\Scripts\activate` (Windows)
3. Установите зависимости:
   `pip install -r requirements.txt`
4. Запустите тесты с генерацией данных для отчета:
   `pytest` (параметр `--alluredir=allure-results` уже прописан в pytest.ini)
5. Откройте HTML-отчет в браузере:
   `allure serve allure-results`

## Тестовые сценарии

Качество покрытия является приоритетом. Ниже представлены позитивные и негативные сценарии для целевых страниц.

### 1. Страница: Ads

Функционал страницы подразумевает появление рекламного окна через 5 секунд.

**Позитивные тесты (7 шт):**
1. Успешная загрузка страницы Ads.
2. Рекламный попап появляется ровно через заданный таймаут (5 секунд).
3. Текст внутри окна соответствует ожидаемому рекламному предложению.
4. Наличие кнопки закрытия в попапе.
5. Успешное закрытие попапа кликом по крестику.
6. Успешное закрытие попапа кликом по оверлею (за пределами окна).
7. Доступность основного контента страницы после закрытия рекламы.

**Негативные тесты (3 шт):**
1. Перехват фокуса: попытка взаимодействия со страницей до закрытия попапа.
2. Блокировка рекламы: поведение страницы при принудительном закрытии через ESC (если поддерживается).
3. Проверка отсутствия дублирования (попап не должен появиться второй раз после закрытия).

### 2. Страница: Modals

Страница содержит кнопки вызова простого модального окна и окна с формой.

**Позитивные тесты (7 шт):**
1. Клик по кнопке "Simple Modal" успешно открывает базовое окно.
2. Текст в Simple Modal содержит ожидаемое приветствие.
3. Закрытие Simple Modal крестиком.
4. Клик по кнопке "Form Modal" открывает модальное окно с формой.
5. Успешный ввод данных в обязательное поле "Name".
6. Успешный ввод данных в поле "Email".
7. Корректная отправка формы с валидными данными.

**Негативные тесты (4 шт):**
1. Отправка формы с пустым полем "Name".
2. Отправка формы с некорректным форматом "Email".
3. Отправка формы с пустым полем "Message".
4. Превышение допустимого количества символов в поле "Message".
